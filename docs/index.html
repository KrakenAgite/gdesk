Vos e-mails Gmail,
dans une vraie application KDE

G-Desk est un client mail natif et libre pour Debian et KDE Plasma. Il utilise l'API officielle de Gmail : pas de navigateur intégré, pas de serveur intermédiaire, pas de pistage.

Fonctionnalités

Tous vos dossiers

Boîte de réception, suivis, envoyés, brouillons, spam, corbeille, catégories et libellés, avec le nombre de non-lus.

Lecture protégée

Les messages HTML s'affichent sans JavaScript et les images distantes (souvent des pisteurs) restent bloquées tant que vous ne les autorisez pas.

Écrire et répondre

Nouveau message, réponse, réponse à tous, transfert avec pièces jointes, brouillons enregistrés dans Gmail, autocomplétion des adresses.

Trier rapidement

Archiver, supprimer, restaurer, spam, lu / non lu, suivi, sur un ou plusieurs messages, au clavier ou à la souris.

Recherche Gmail

La syntaxe de recherche de Gmail fonctionne telle quelle : from:, has:attachment, after:2026/01/01…

Intégré à KDE

Notifications Plasma, pastille de non-lus dans la barre système, jeton rangé dans KWallet, application par défaut pour les liens mailto:.

Installation

Téléchargez le paquet ci-dessus, puis installez-le depuis un terminal (ou double-cliquez dessus dans Dolphin) :

sudo apt install ./gdesk_2.0.0_amd64.deb

G-Desk apparaît ensuite dans le menu des applications, rubrique Internet. Pour le désinstaller :

sudo apt remove gdesk

Pour vérifier que le fichier téléchargé est intact, comparez son empreinte avec celle affichée plus haut :

sha256sum gdesk_2.0.0_amd64.deb

Première utilisation

Google impose que toute application utilisant l'API Gmail ait son propre « client OAuth ». Vous le créez une seule fois, gratuitement, dans votre compte Google Cloud. Ainsi vos e-mails circulent directement entre votre ordinateur et Google, sans passer par un tiers. L'assistant de G-Desk vous guide :

  1. Créez un projet sur la console Google Cloud.
  2. Activez l'API Gmail.
  3. Dans Google Auth Platform, configurez l'écran de consentement (audience Externe).
  4. Dans Audience, ajoutez votre adresse comme utilisateur test, puis cliquez sur Publier l'application.
  5. Dans Clients, créez un client de type Application de bureau et téléchargez le fichier JSON.
  6. Dans G-Desk, importez ce fichier puis cliquez sur Se connecter avec Google.

Google affichera « Google n'a pas validé cette application » : c'est normal, il s'agit de votre propre projet. Cliquez sur Paramètres avancés puis Accéder à G-Desk.
